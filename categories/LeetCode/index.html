leetcode t704 二分查找

给定一个 n 个元素有序的（升序）整型数组 nums 和一个目标值 target ，写一个函数搜索 nums 中的 target，如果 target 存在返回下标，否则返回 -1。

你必须编写一个具有 O(log n) 时间复杂度的算法。

提示：

  • 你可以假设 nums 中的所有元素是不重复的。

  • n 将在 [1, 10000]之间。

  • nums 的每个元素都将在 [-9999, 9999]之间。

二分查找的前提:

  1. 有序；
  2. 无重复元素。

二分查找的区间定义

左闭右闭 [left, right]

要点:

  • while (left <= right) 要使用 <= ，因为left == right是有意义的，所以使用 <=
  • if (nums[middle] > target) right 要赋值为 middle - 1，因为当前这个nums[middle]一定不是target，那么接下来要查找的左区间结束下标位置就是 middle - 1

左闭右开 [left, right)

要点：

  • while (left < right)，这里使用 < ,因为left == right在区间[left, right)是没有意义的

  • if (nums[middle] > target) right 更新为 middle，因为当前nums[middle]不等于target，去左区间继续寻找，而寻找区间是左闭右开区间，所以right更新为middle，即：下一个查询区间不会去比较nums[middle]

Leetcode t977 有序数组的平方

给你一个按 非递减顺序 排序的整数数组 nums，返回 每个数字的平方 组成的新数组，要求也按 非递减顺序 排序。

思路：双指针法，注意，题目不要求空间复杂度。

由于非递减，且是比较每个数字的平方，大小顺序就不能按照原数组大小顺序定，且大小一定是从两边到中间变小，因为有0的存在；

所以双指针就可以从两边开始，一个从左往右，一个从右往左；

实际上应该是三指针，因为新的数组还有一个从大到小的定位指针。

Leetcode 27 移除元素

给你一个数组 nums 和一个值 val，你需要 原地 移除所有数值等于 val 的元素。元素的顺序可能发生改变。然后返回 nums 中与 val 不同的元素的数量。
假设 nums 中不等于 val 的元素数量为 k，要通过此题，您需要执行以下操作：
更改 nums 数组，使 nums 的前 k 个元素包含不等于 val 的元素。nums 的其余元素和 nums 的大小并不重要。
返回 k。

思路：快慢指针法

慢指针：指向更新数组新数组下标的位置;

快指针：寻找新数组的元素，即与目标值不等的元素.

Leetcode 26 删除有序数组中的重复项

给你一个 非严格递增排列 的数组 nums ，请你 原地 删除重复出现的元素，使每个元素 只出现一次 ，返回删除后数组的新长度。元素的 相对顺序 应该保持 一致 。然后返回 nums 中唯一元素的个数。
考虑 nums 的唯一元素的数量为 k。去重后，返回唯一元素的数量 k。
nums 的前 k 个元素应包含 排序后 的唯一数字。下标 k - 1 之后的剩余元素可以忽略。

思路：快慢指针

与Leetcode 27不同的地方在于，不显式提供目标值，但是仍然有目标值，即slow指针的指向。

注意，虽然是删除，但是我们仍要保留元素至少出现一次，也就是说，当元素第一次出现时，我们要保留，不能删除，但元素接下来再出现，就需要覆盖

所以slow指针，不仅指向了目标值，也指向了我们要保留的唯一元素

数组是非严格递增，那么相同数值大小的元素就一定在数组中相邻，我们只需要找到元素出现的第一个位置，那么后面所有出现的元素，我们都可以直接覆盖掉
